# Как открыть CRM одним щelчком (без консоли)

## Обычное использование

1. Откройте папку проекта на компьютере.
2. Дважды кликните по файлу **`Открыть CRM.vbs`**.
3. Приложение откроется в браузере по умолчанию. Никакого окна консоли не появится.

Если хотите — можно перетащить `Открыть CRM.vbs` на Рабочий стол как ярлык
(правой кнопкой → «Отправить» → «Рабочий стол (создать ярлык)»), тогда запуск
будет буквально одним кликом с рабочего стола.

> Совет: можно сменить иконку ярлыка на любую картинку через
> «Свойства ярлыка → Изменить значок».

## Важно про данные

Все данные (задачи, студии, метрики, интервью, журнал) хранятся **прямо в
браузере** на этом компьютере (localStorage), привязаны к конкретному файлу
`dist/index.html`. Поэтому:

- **Не переименовывайте и не перемещайте** файл `dist/index.html` — иначе
  браузер посчитает, что это «другой сайт», и данные покажутся пустыми.
- Открывайте CRM всегда через `Открыть CRM.vbs` (он всегда указывает на один
  и тот же файл), а не через случайные копии `index.html`.
- Периодически делайте резервную копию: во вкладке «Журнал + Экспорт» есть
  кнопка экспорта данных в JSON-файл. Храните эти файлы отдельно (например, в
  папке `backups`), на случай если браузер вдруг почистит localStorage.

## Если нужно изменить исходный код (для разработчика)

Файл `dist/index.html`, который открывается по клику, — это готовая сборка.
Если вы (или кто-то с вашего согласия) поменяли код в папке `src`, нужно
пересобрать приложение:

1. Дважды кликните **`Пересобрать CRM.bat`** (один раз потребуется скачать
   зависимости — нужен установленный [Node.js](https://nodejs.org/), если его
   ещё нет на компьютере).
2. Дождитесь надписи «Готово!».
3. Снова открывайте через `Открыть CRM.vbs` — там уже будет обновлённая версия.

Для повседневной работы с CRM (ввод данных, просмотр roadmap и т.п.)
пересборка **не требуется** — только `Открыть CRM.vbs`.
